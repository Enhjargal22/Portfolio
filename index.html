Tech Stack

React 19 TypeScript Material UI 5 Recharts Framer Motion jsPDF SheetJS (XLSX) Spring Boot 3.2 Java 17 Spring Security (JWT) Spring Data JPA MySQL Kotlin Jetpack Compose Hilt DI Retrofit REST API

Key Features

  • Budget Limits & Alerts — Category-based spending caps with progress visualizers and threshold warnings
