BLAZE.by — Sports Magazine & E-Commerce Platform

A full-stack sports e-commerce platform with product catalog, shopping cart, order management, user authentication (JWT), admin & analyst dashboards, content management, personalized product recommendations, smart search, and a built-in analytics system. Includes an Android mobile app.

Tech Stack

React 18 TypeScript Material UI 5 Vite Recharts Spring Boot 3 Java 17 Spring Security JPA / Hibernate MySQL Android (Kotlin) JWT Auth REST API OpenAPI / Swagger

Key Features

  • Storefront — Product catalog with categories, detail pages, image zoom, favorites, and smart search
  • Shopping — Cart, checkout flow, order history
  • Auth & Roles — Registration, login (JWT), role-based access (Buyer, Admin, Analyst, Content Manager)
  • Admin Dashboard — User management, product CRUD, order processing
  • Analytics Dashboard — User-behavior event tracking, session analytics, data visualizations (Recharts)
  • Content Manager — Articles/news publishing system with rich editing
  • Recommendations — Personalized product suggestions based on user activity
  • Android App — Native mobile client for the platform
